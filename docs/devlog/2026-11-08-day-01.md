# 2026-11-08: project and repo started

**Milestone:** M0

## What I set out to do

Start a micromouse project and build it one tested step at a time, without ordering or wiring anything I do not yet understand.

## What I did

- Studied the maze algorithms (wall following, flood fill, modified flood fill, search strategies, Dijkstra and A*, diagonals, data structures) and wrote notes.
- Wrote flood fill in the simulator, first in Python, then in C++.
- Studied motion and control, sensors and electronics, and wrote notes for each.
- Decided: the brain is an ESP32, and the maze and control code stays portable so the chip can be swapped later.
- Created this repository, with a portable maze library and unit tests that run on a PC.

## What I measured or saw

Six unit tests pass on the maze library (`./run_tests.sh`).

## What went wrong, and what I learned

I do not have an ESP32 with me yet, so the roadmap puts everything that can be tested on a PC first.
